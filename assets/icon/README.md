# Fast Diff Viewer app icon

This directory owns the app icon. Windows embeds the shell icon into
`fast-diff-viewer.exe` through `build.rs`, all targets attach the runtime
viewport icon through `src/main.rs`, Ubuntu release archives include the SVG
for launcher integration, and macOS release archives derive their `.icns`
bundle icon from the PNG source.

## Files

| File | Role |
| --- | --- |
| `fast-diff-viewer.svg` | Human-editable vector master. Source-of-truth for the mark's geometry and shipping colorway. |
| `fast-diff-viewer.ico` | Multi-resolution (16, 20, 24, 32, 40, 48, 64, 128, 256) ICO compiled into the PE `IDI_ICON1`. |
| `fast-diff-viewer.png` | 1024 x 1024 PNG source for the macOS release workflow's `.icns` generation. |
| `window_icon.rgba.bin` | 256 x 256 RGBA8 buffer `include_bytes!`'d by `main.rs` for the live window / task switcher icon. |

Generated icon artifacts are regenerated by code in `scripts/gen_icon.rs`.
`fast-diff-viewer.svg` is the human-facing source; the generated artifacts are
committed to the repo so everyday `cargo build --release` never runs
the rasterizer.

## Regenerating

After changing `fast-diff-viewer.svg`, the shipping (`Graphite`) inline palette
in `src/theme.rs`, or the `REMOVED_INLINE` / `ADDED_INLINE` /
`RING_INK` constants in `scripts/gen_icon.rs`:

```text
cargo run --example gen_icon --release
```

That rewrites `fast-diff-viewer.ico`, `fast-diff-viewer.png`, and
`window_icon.rgba.bin`. Commit the source and generated outputs together so
they stay in lockstep.

## Colorway rationale

The in-app brand mark painted by `draw_brand_mark` (`src/main.rs`) is
theme-reactive: it mirrors the active theme's `removed_inline` /
`added_inline` pair. Platform package icons are static, so Explorer, Finder,
desktop launchers, taskbars, and Alt-Tab surfaces render one fixed image
regardless of the user's light/dark preference.

The shell icon therefore locks to the **Graphite** shipping theme's inline
pair:

* `removed_inline` = `#A0384A`  (top-left half)
* `added_inline`   = `#316D4C`  (bottom-right triangle)
* ring             = `#E6E1D6` at ~15% opacity (`ink`)

Graphite is the palette the app ships in by default, so the package icon
matches the first-run in-app mark a user sees. Both Graphite values clear
WCAG AA against Graphite ink, and both also read legibly against common shell
backgrounds without pulling the mark apart.

The hairline ring is dropped for rendered sizes below 24 px so it
does not collapse into a muddy pixel at 16 / 20 px shell list views.
